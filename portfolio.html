Java Queues and Deques Sets File Handling

Emergency Dispatch System

A Java command-line application designed to record and manage emergency incidents. The system prioritises incidents using queue and deque structures, allowing high-priority incidents to be handled first.

I implemented incident management, searching by incident type and district, unique incident tracking, set-based trend analysis, file saving and loading, and input validation.

Developing this project strengthened my understanding of data structures and file handling. A challenge was managing incident priorities and implementing the different data operations reliably. I also developed and used a test plan to identify and correct issues.

C Hash Tables Linked Lists Memory Management

Hash Table Login System

A C-based user login and registration system using a hash table with linked-list chaining to manage collisions. The hash function distributes user IDs across eleven buckets.

I implemented hash table initialisation, user lookup, registration and updating, password validation, loading user records from a file and freeing allocated memory.

This project developed my understanding of pointers, linked lists, hashing and dynamic memory management. I also practised debugging and input validation while working with C.

Assessment result: 99/100 (A1)

Java Game Development Object-Oriented Programming File Handling

Project Nova – Interactive Puzzle Game

A two-player, turn-based Java game built around a 16×16 grid. Players explore the board to discover hidden creatures while encountering traps and power-ups.

I developed the game logic, board system, creature database, player management, scoring, health system and save/load functionality. The game also includes different ways to sort the creature database.

This project helped me develop skills in object-oriented programming, game logic, class organisation and file handling. One challenge was managing interactions between the board, players and game state.

The final version uses a text-based interface after I found that completing the graphical interface within the available time was too complex.
