Hash table visualisation

The table has 11 buckets. Each user ID is assigned to a bucket using the remainder after division by 11.

Hash function: user ID % 11

How collision handling works

When two user IDs produce the same bucket number, they are stored in the same bucket using a linked-list chain. This is called separate chaining.

For example, IDs 12 and 23 both map to bucket 1 because 12 % 11 = 1 and 23 % 11 = 1.
